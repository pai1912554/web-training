🏆 ค่ายซ้อมเว็บ 3 วัน

เตรียมแข่งสร้าง Webpage ประเภท Text Editor — ศิลปหัตถกรรม ม.ต้น

วัน 1 — HTML: โครงกระดูกของเว็บ

เป้าหมายวันนี้: พิมพ์โครงเว็บได้จากความจำ + ใช้ tag หลักครบทุกตัว

1.1 โครงหลักที่ต้องจำขึ้นใจ

ทุกเว็บเริ่มแบบนี้เสมอ — วันแข่งพิมพ์ ! แล้วกด Tab ใน VS Code โครงขึ้นเองทันที

<!DOCTYPE html>
<html lang="th">
<head>
  <meta charset="UTF-8">
  <title>ชื่อบนแท็บ</title>
</head>
<body>
  <!-- ทุกอย่างที่คนเห็น อยู่ตรงนี้ -->
</body>
</html>
  • <head> = หลังบ้าน (ชื่อแท็บ, ตั้งค่า) — คนไม่เห็น
  • <body> = หน้าบ้าน — ทุกอย่างที่โชว์
  • charset="UTF-8" = ทำให้ภาษาไทยไม่เพี้ยน ห้ามลืม
1.2 ข้อความ: หัวข้อ + ย่อหน้า 
<h1>หัวข้อใหญ่สุด (มีอันเดียวต่อหน้า)</h1>
<h2>หัวข้อรอง</h2>
<h3>หัวข้อย่อย</h3>
<p>ย่อหน้าปกติ มี <b>ตัวหนา</b> และ <i>ตัวเอียง</i> ได้</p>
<hr> <!-- เส้นคั่น -->
<br> <!-- ขึ้นบรรทัดใหม่ -->
1.3 รูปภาพ + ลิงก์ 
<!-- รูป: src = ที่อยู่รูป, alt = คำอธิบาย (กรรมการดู!) -->
<img src="cat.jpg" alt="แมวส้ม" width="300">

<!-- ลิงก์ไปเว็บอื่น -->
<a href="https://www.google.com">ไปกูเกิล</a>

<!-- ลิงก์ไปหน้าอื่นของเราเอง -->
<a href="page2.html">หน้าถัดไป</a>

⚠️ <img> ไม่มี tag ปิด. วันแข่งเซฟรูปไว้โฟลเดอร์เดียวกับ index.html แล้วใช้ชื่อไฟล์ตรง ๆ

1.4 ลิสต์ (รายการ) 
<!-- จุดนำหน้า -->
<ul>
  <li>ข้อแรก</li>
  <li>ข้อสอง</li>
</ul>

<!-- ตัวเลขนำหน้า -->
<ol>
  <li>อันดับหนึ่ง</li>
  <li>อันดับสอง</li>
</ol>
1.5 ตาราง (กรรมการชอบมาก) 
<table border="1">
  <tr>
    <th>ชื่อ</th><th>ราคา</th>
  </tr>
  <tr>
    <td>ข้าวผัด</td><td>50</td>
  </tr>
</table>
  • tr = แถว, th = หัวตาราง, td = ช่องข้อมูล
  • จำ: ตาราง→แถว→ช่อง เรียงจากนอกเข้าใน
1.6 กล่องแบ่งโซน (สำคัญสุดสำหรับจัดหน้า) 
<header>ส่วนหัวเว็บ (โลโก้ ชื่อเว็บ)</header>
<nav>เมนู</nav>
<main>เนื้อหาหลัก</main>
<footer>ท้ายเว็บ (ชื่อผู้จัดทำ)</footer>

<!-- กล่องเปล่าเอนกประสงค์ -->
<div class="box">อะไรก็ได้</div>

ใช้ header/nav/main/footer = ดูโปร กรรมการให้คะแนนโครงสร้าง

✅ การบ้านวัน 1

พิมพ์โครงเว็บจากความจำ ไม่ดูโพย 3 รอบ
ทำหน้า "แนะนำตัวเอง" มี h1, p, รูป 1 รูป, ลิสต์งานอดิเรก
เพิ่มตารางตารางเรียน 5 วัน
แบ่งหน้าเป็น header / main / footer

วัน 2 — CSS: แต่งให้สวย

เป้าหมายวันนี้: เว็บขาว ๆ กลายเป็นเว็บมีสี มีเมนู มีการ์ด เหมือนเว็บจริง

2.1 CSS เขียนตรงไหน

วางใน <head> แบบนี้ (วิธีเดียวพอสำหรับแข่ง):

<head>
  <style>
    body { background-color: lightyellow; }
    h1   { color: purple; }
  </style>
</head>

สูตร: ตัวไหน { แต่งอะไร: ยังไง; }

2.2 เลือกเป้าหมาย: tag / class / id 
p        { color: gray; }   /* p ทุกตัว */
.card    { padding: 16px; } /* ตัวที่มี class="card" */
#logo    { width: 80px; }   /* ตัวที่มี id="logo" (ใช้ครั้งเดียว) */

จำ: จุด = class, ชาร์ป = id. งานแข่งใช้ class เป็นหลักพอ

2.3 คำสั่งแต่งที่ใช้บ่อยสุด 12 ตัว
คำสั่งทำอะไรตัวอย่าง
colorสีตัวอักษรcolor: #7c3aed;
background-colorสีพื้นหลังbackground-color: #f3e8ff;
font-sizeขนาดตัวอักษรfont-size: 20px;
font-familyแบบตัวอักษรfont-family: Tahoma;
text-alignจัดข้อความtext-align: center;
paddingระยะห่างในกล่องpadding: 16px;
marginระยะห่างนอกกล่องmargin: 10px;
borderเส้นขอบborder: 2px solid purple;
border-radiusมุมโค้งborder-radius: 10px;
widthความกว้างwidth: 300px;
box-shadowเงา (ดูโปรทันที)box-shadow: 0 4px 10px #0003;
background: linear-gradient(...)สีไล่เฉดlinear-gradient(135deg,#7c3aed,#ec4899)

จำภาพ: margin = ถอยห่างเพื่อนบ้าน, padding = เบาะในกล่อง, border = กำแพง

2.4 Flexbox: เรียงของในแถวเดียว

อยากให้ของเรียงแนวนอน (เมนู, การ์ด 3 ใบ) — ใส่ที่ตัวแม่:

.row {
  display: flex;
  gap: 16px;              /* ช่องว่างระหว่างลูก */
  justify-content: center; /* จัดกลางแนวนอน */
  align-items: center;     /* จัดกลางแนวตั้ง */
}

รู้แค่ 4 บรรทัดนี้ ทำเมนู + การ์ดได้หมด

2.5 เมนูบาร์สำเร็จรูป (จำไปใช้วันแข่งเลย) 
<!-- HTML -->
<nav>
  <a href="#home">หน้าแรก</a>
  <a href="#about">เกี่ยวกับ</a>
  <a href="#contact">ติดต่อ</a>
</nav>

/* CSS */
nav { display: flex; gap: 20px; justify-content: center;
      background: #4c1d95; padding: 14px; }
nav a { color: white; text-decoration: none; font-weight: bold; }
nav a:hover { color: #fbbf24; }

:hover = ตอนเมาส์ชี้ — ใส่แล้วเว็บดูมีชีวิต กรรมการชอบ

2.6 การ์ดสวย ๆ สำเร็จรูป 
.card {
  background: white;
  border-radius: 12px;
  box-shadow: 0 4px 12px rgba(0,0,0,.15);
  padding: 20px;
  width: 250px;
}
.card img { width: 100%; border-radius: 8px; }

เอา 3 ใบใส่ใน <div class="row"> (flex) = หน้าเว็บโปรทันที

✅ การบ้านวัน 2

เอาเว็บแนะนำตัวเมื่อวาน มาใส่สี + font + จัดกลาง
ทำเมนูบาร์ 3 ลิงก์ มี hover
ทำการ์ด 3 ใบเรียงแถวด้วย flexbox
ใส่ gradient ที่ header

📝 ซ้อม Notepad ให้ชิน (สำคัญสุด!)

  1. เปิด Notepad: กด Win พิมพ์ notepad กด Enter
  2. พิมพ์โครงเว็บจากความจำ — ไม่มีตัวช่วยเลย นี่แหละของจริง
  3. เซฟ: File → Save As → ตั้งชื่อ index.html → ช่อง Encoding เลือก UTF-8 (ลืม = ภาษาไทยเพี้ยน!) → ช่อง Save as type เลือก All Files
  4. เปิดไฟล์ด้วย Chrome ดูผล → แก้ใน Notepad → กด Ctrl+S → กลับไป Chrome กด F5

ตารางซ้อม: ทำภารกิจในเว็บนี้ให้เข้าใจก่อน แล้ว "ทำซ้ำด่านเดิมใน Notepad" — เว็บนี้ = ห้องเรียน, Notepad = สนามจริง

ข้อดีที่ซ่อนอยู่: ซ้อม Notepad จนคล่อง วันแข่งจะเร็วกว่าคู่แข่งที่ซ้อมแต่ VS Code แล้วไปงงหน้างาน

🗂 สูตรเว็บ 3 หน้า (บังคับตามเกณฑ์!)

โครงโฟลเดอร์ที่ควรใช้:

งานแข่ง/
  index.html      (หน้าแรก)
  page2.html      (เนื้อหาหลัก)
  page3.html      (ผู้จัดทำ/ติดต่อ + ฟอร์ม)
  images/         (รูปที่กรรมการแจก copy มาไว้นี่)

เมนูเดียวกัน วางทุกหน้า — ลิงก์ใช้ชื่อไฟล์ตรง ๆ:

<nav>
  <a href="index.html">หน้าแรก</a>
  <a href="page2.html">เนื้อหา</a>
  <a href="page3.html">ผู้จัดทำ</a>
</nav>

<!-- รูปจากไฟล์ในเครื่อง (ไม่ใช่ลิงก์เน็ต!) -->
<img src="images/pic1.jpg" alt="คำอธิบายรูป">
  • ชื่อไฟล์: อังกฤษล้วน ตัวเล็ก ไม่มีช่องว่าง — page2.html ไม่ใช่ หน้า 2.HTML
  • เคล็ดลับเร็ว: ทำ index.html เสร็จ 1 หน้า (โครง+เมนู+footer) → copy ไฟล์เป็น page2, page3 → แก้แค่เนื้อหากลาง
  • CSS ก็ copy ทั้งก้อน <style> ไปทุกหน้า = ธีมเดียวกันอัตโนมัติ
  • เช็คก่อนส่ง: กดเมนูครบทุกลิงก์ ทุกหน้า ไป-กลับได้หมด (10 คะแนนตรงนี้)

💪 ซ้อมเลย: ทำโปรเจกต์ 3 หน้าหัวข้อ "โรงเรียนของฉัน" ใน Notepad แล้วส่งรูป/โค้ดมาให้ผมตรวจในแชท

📤 FTP คืออะไร + ซ้อมยังไง (10 คะแนนฟรี)

FTP = ส่งไฟล์จากเครื่องเราขึ้น server. วันแข่งกรรมการแจก Host/IP, Username, Password, Port

  1. โปรแกรมยอดฮิต: FileZilla (ฟรี) — โหลดมาซ้อมที่บ้านได้
  2. กรอก 4 ช่องบน: Host, Username, Password, Port → กด Quickconnect
  3. ฝั่งซ้าย = เครื่องเรา, ฝั่งขวา = server → ลากไฟล์ทั้งหมด (ทุก .html + โฟลเดอร์ images) จากซ้ายไปขวา
  4. เช็คว่าไฟล์ขึ้นครบ แล้วเปิดเว็บผ่าน browser ตาม URL ที่กรรมการให้ ดูว่ารูปไม่แตก ลิงก์ไม่ตาย

กับดักคลาสสิก: อัปแต่ .html ลืมโฟลเดอร์ images → รูปแตกหมด. ลากขึ้นทั้งยวง!

🧠 ได้โจทย์แล้วทำอะไรก่อน (15 นาทีแรกชี้ชะตา)

  1. อ่านโจทย์ 2 รอบ — วงคำสำคัญ: หัวข้ออะไร บังคับมีอะไรบ้าง
  2. เปิดดูไฟล์ที่กรรมการแจกทันที — มีรูปอะไร กี่รูป มีข้อความ/วิดีโอไหม → ของพวกนี้คือ "วัตถุดิบ" วางแผนจากของที่มี
  3. ร่างบนกระดาษ (กรรมการแจกดินสอ+กระดาษ): 3 หน้า หน้าไหนใส่อะไร ใช้รูปไหน
  4. แบ่งงานในทีม: คนหนึ่งลุยโครง+เนื้อหา อีกคนคิดเนื้อหา/เขียนข้อความบนกระดาษรอ
  5. เขียนเนื้อหาจากความรู้ตัวเอง — หัวข้อแข่งมักเป็นเรื่องใกล้ตัว (จังหวัด ประเพณี สิ่งแวดล้อม เศรษฐกิจพอเพียง) อ่านรอบตัวไว้เยอะ ๆ

🔎 ถ้าเขตของคุณให้ใช้เน็ต — สูตรค้นให้ไว

  • ค้นเนื้อหา: หัวข้อ + ประวัติ, หัวข้อ + ความสำคัญ, หัวข้อ + 5 ข้อ (ได้ลิสต์สำเร็จ)
  • ห้าม copy ทั้งดุ้น — อ่านแล้วสรุปเป็นภาษาตัวเอง 2-3 ประโยคต่อหัวข้อ (กรรมการจับ copy ได้ = คะแนนเนื้อหาหาย)
  • หารูป: Google Images → Tools → ขนาดใหญ่ | หรือ pexels.com / unsplash.com (รูปฟรีไม่ติดลิขสิทธิ์)
  • ลืม tag: w3schools + ชื่อ tag — เปิดดู 10 วิ ปิด อย่าไถยาว
  • กติกาเวลา: ค้นข้อมูลรวมไม่ควรเกิน 20 นาทีทั้งการแข่ง — เวลาที่เหลือคือเขียนโค้ด

📦 สไตล์การเขียนของฉัน — "คิดเป็นกล่อง"

สูตรประจำตัว ใช้ทุกเว็บ ทุกโจทย์:

  1. มองหน้าเว็บเป็นกล่องซ้อนกล่อง — ทั้งหน้า = กล่องใหญ่, ข้างในมี กล่องหัว / กล่องเมนู / กล่องเนื้อหา / กล่องท้าย
  2. ทุกกล่องตั้งชื่อด้วย class — <header class="top">, <div class="card"> — id ใช้เฉพาะตัวที่มีตัวเดียวจริง ๆ
  3. สีประกาศเป็นตัวแปรที่ :root ก่อนเสมอ — แล้วทั้งเว็บเรียก var(--main) อยากเปลี่ยนธีมแก้ที่เดียว
  4. แต่งทีละกล่อง จากนอกเข้าใน — กล่องใหญ่ก่อน (พื้น, จัดกลาง) ค่อยลงกล่องย่อย
:root {
  --main: #7c3aed;   /* สีหลัก */
  --accent: #ec4899; /* สีเน้น */
  --bg: #faf5ff;     /* สีพื้น */
}
.top     { background: var(--main); }
.card    { border: 2px solid var(--accent); }

ในภารกิจฝึก/สนามลอง: !+Tab = โครง VS Code เป๊ะ · !!+Tab = โครงเต็มสไตล์ฉัน (reset + .container + nav + hero)

โปรเจกต์จริงใน VS Code: แยก CSS เป็นไฟล์ style.css แล้วดึงด้วย <link rel="stylesheet" href="style.css"> — เว็บซ้อมนี้เป็นไฟล์เดียวเลยรวมใน <style> แทน หลักการเดียวกัน
